# Customer-Churn-Analysis-and-Prediction

This project focuses on analyzing telecom customer behaviour and building machine learning models to predict customer churn. The objective is to identify key factors influencing churn and help telecom companies improve customer retention strategies.

---

## Project Workflow

- Data Cleaning and Preprocessing  
- Exploratory Data Analysis (EDA)  
- Feature Engineering  
- Machine Learning Model Building  
- Model Evaluation and Comparison  
- Interactive Churn Prediction Web Application  

---

## Machine Learning Models Used

- Random Forest Classifier  
- Gradient Boosting Classifier  

### Model Performance

- Random Forest Accuracy: **0.8019**  
- Gradient Boosting Accuracy: **0.8026**

## Key Insights

- Customers with low tenure and month-to-month contracts show higher churn risk  
- Higher monthly charges are associated with increased churn probability  
- Lack of support services such as Tech Support and Online Security impacts retention  
- Long-term contract customers demonstrate stronger loyalty
